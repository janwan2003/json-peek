Privacy

JSON Peek collects no data. No analytics, no telemetry, no accounts, no cookies, no ads, no affiliate links.

Browser extension

  • It reads the text of a page only when that page is a raw JSON document (for example an API response opened in a tab), and renders it in that tab.
  • It makes no network requests and loads no remote code. Everything it runs is in the published package, which is the unminified source from the GitHub repository.
  • Its only API permission is storage, used to remember two display settings (theme and path style) on your device.
  • It needs access to all sites because a JSON response can come from any URL. It ignores every page that is not raw JSON.

Website

  • JSON you paste, drop or open is processed in your browser tab and is never sent anywhere.
  • Your display settings are kept in your browser's local storage.
  • The site is hosted on GitHub Pages. GitHub may keep standard server logs for page requests; see GitHub's privacy statement.

Questions: open an issue on GitHub.
