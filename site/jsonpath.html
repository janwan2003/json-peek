JSONPath tester: try JSONPath queries on your JSON

Paste JSON below, then type a query that starts with $ in the viewer's search box. Matches are highlighted in the tree. Press Enter to step through them, or tick Filter to hide everything else. It runs locally, and big numbers stay exact.

Everything runs locally in this tab. Big files open from Open file without being copied into the text box.

JSONPath syntax supported

$The root
$.store.book, $['store']['book']Child by name (use brackets for keys with spaces or symbols)
$.items[0], $.items[-1]Array element by index; negative counts from the end
$.items[0:5], $.items[::2]Slices (start:end:step)
$.items[*], $.user.*All children
$..idRecursive descent: every id at any depth
$.items[0,2], $['a','b']Unions
$.items[?(@.price > 10)]Filter with == != < <= > >= against a number, string, true, false or null
$.items[?(@.tags)]Filter by existence of a key
$.items[?(@.address.city == "Oslo")]Filters can look into nested objects

Not supported yet: script expressions, functions such as length(), and boolean && / || inside filters.

Use it on every JSON URL: the JSON Peek extension

The browser extension shows the same viewer automatically whenever you open a JSON API response, a .json file, or an application/x-ndjson stream.

Exact big numbers

JSON.parse rounds 9007199254740993 to 9007199254740992, and most viewers inherit that bug. Database IDs, Twitter/X snowflakes and Discord IDs are then shown wrong. JSON Peek parses the text itself and shows every number exactly as it was sent. Numbers that JavaScript would change get an exact badge.

Fast on large files

The tree is virtualised: only the rows on screen exist in the page. A 50 MB file with 3.3 million values is parsed in about a second, and scrolling stays smooth.

Search and JSONPath

Type text to search keys and values, and tick Filter to hide everything else. Start with $ to run a JSONPath query such as $.items[?(@.price > 10)].name or $..id.

Copy paths, values and subtrees

Select any value to see its path ($.data[3].id, jq .data[3].id or JavaScript style). Then copy the path, the value or the formatted subtree.

Original key order

Keys are shown in the order the server sent them. Viewers built on JSON.parse move numeric keys like "10" to the top.

FAQ

Is my JSON uploaded anywhere?

No. This page is static HTML and JavaScript. Parsing, formatting and search run in your browser tab, and the page sends no requests with your data. It works offline once loaded.

Why does another formatter show a different number than my API returned?

JavaScript numbers are 64-bit floating point. Integers above 253 (9,007,199,254,740,992) cannot all be represented, so JSON.parse silently rounds them. JSON Peek keeps the digits from the source text. Format, minify and copy reproduce them unchanged.

How do I validate JSON?

Paste it above. If it is invalid, you get the reason with the line and column, and the offending line highlighted. Common causes: trailing commas, single quotes, unquoted keys, comments.

Can it open JSON Lines / NDJSON?

Yes. Tick JSON Lines, or open a .jsonl / .ndjson file. Each line becomes one item in a list you can search and filter.

What JSONPath syntax is supported?

$, .key, ['key'], [0], [-1], [0:5], [*], ..key (recursive), unions like [0,2], and filters such as [?(@.age >= 18)] or [?(@.tags)].
